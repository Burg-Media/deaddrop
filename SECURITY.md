# Beveiligingsproblemen melden

Vind je een kwetsbaarheid in Deaddrop, meld die dan niet in een publieke issue. Mail naar
**info@burgmedia.eu** (onderwerp: Deaddrop security) met:

- wat het probleem is en welke versie (zie `/verify.php` of het bestand `VERSION`)
- hoe het te reproduceren is
- wat een aanvaller ermee kan

We spreken samen af wanneer het probleem
openbaar wordt, nadat er een oplossing is.

Lees eerst [docs/threat-model.md](docs/threat-model.md): punten die daar onder "waartegen het
niet beschermt" staan (zoals een operator die de JavaScript aanpast), zijn bekend.
